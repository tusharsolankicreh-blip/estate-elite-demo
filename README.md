# Estate Elite

A responsive, static luxury real-estate demo website for an international brand. Open `index.html` in a browser or serve this folder with any static web server. No build step or dependencies are required.

## Demo features

- Responsive navigation and layouts
- Property search, type filtering, price sorting, and saved homes
- Property detail dialog with descriptions and enquiry links
- Destination shortcuts, rotating testimonials, and validated enquiry form
- Placeholder contact information and client-side-only enquiry success state

All homes, people, prices, reviews, and contact details are fictional demo content. Photos and web fonts load from external providers.

## GitHub Pages

This folder is ready to publish as the root of a GitHub repository or from a `/docs` folder. GitHub Pages can serve `index.html` directly; no build workflow is needed.
